# حديقة القرآن — تطبيق أندرويد

غلاف أندرويد (WebView) لتطبيق حديقة القرآن. ملفات التطبيق داخل `app/src/main/assets/www/`.

## الطريقة ١: بناء الـAPK مجاناً على GitHub (بدون تثبيت أي شيء)
1. أنشئ مستودعاً جديداً (Private) على github.com.
2. ارفع كل محتويات هذا المجلد (Add file ← Upload files ← اسحب الملفات والمجلدات، ومنها `.github`).
3. افتح تبويب **Actions** ← سيبدأ «Build APK» تلقائياً (٥–٨ دقائق).
4. افتح التشغيل المكتمل ← في الأسفل **Artifacts** ← نزّل `quran-garden-apk` ← فك الضغط ← `app-release.apk`.

## الطريقة ٢: Android Studio
File ← Open ← اختر هذا المجلد ← انتظر Sync ← Build ← Build App Bundle(s) / APK(s) ← Build APK(s).

## التثبيت على التابلت
انقل ملف `app-release.apk` للتابلت ← افتحه ← اسمح بـ«التثبيت من مصادر غير معروفة» ← تثبيت.

## ☁️ المزامنة المدمجة (مرة واحدة)
افتح `app/src/main/assets/www/config.js` والصق رابط Firebase Realtime Database بين علامتي التنصيص.
بعدها كل من يثبّت التطبيق يُسأل عند أول فتح: «أنا الوالد — أنشئ عائلة» أو «جهاز طفل — انضم بالرمز».
كل عائلة لها رمز سري خاص، ولا ترى أي عائلة بيانات غيرها.

## تحديث محتوى التطبيق
استبدل `app/src/main/assets/www/index.html` بالنسخة الجديدة، وزد `versionCode` في `app/build.gradle.kts`، ثم ابنِ من جديد.
البيانات (التقدّم والأسماء) تبقى بعد التحديث طالما لم تحذف التطبيق.
